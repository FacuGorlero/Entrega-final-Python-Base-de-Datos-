# 📦 Sistema de Inventario en Python con SQLite

Este proyecto es un sistema de gestión de inventario desarrollado en **Python**, utilizando **SQLite** como base de datos. Funciona completamente desde la **terminal** y permite administrar productos de forma simple y ordenada.

El sistema está dividido en tres módulos para una mejor organización del código:
- Base de datos y operaciones CRUD
- Interfaz de usuario y validaciones
- Lógica principal del programa

---

## 🚀 Funcionalidades

✅ Registrar productos  
✅ Ver todos los productos  
✅ Buscar productos por ID  
✅ Buscar por nombre o categoría  
✅ Actualizar productos  
✅ Eliminar productos  
✅ Reporte de productos con bajo stock  
✅ Persistencia de datos con SQLite  
✅ Interfaz por consola con colores (opcional con colorama)

---

## 🛠️ Tecnologías utilizadas

- Python 3
- SQLite3
- Colorama (opcional)
